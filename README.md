# Variáveis do CAF

Seleção de variáveis PF e PJ com justificativas obrigatórias e recortes independentes por modalidade. Gera XLSX com abas PF e PJ e prepara e-mail para caf@mda.gov.br. O usuário anexa a planilha e confirma o envio em seu aplicativo de e-mail.

## Desenvolvimento

`npm ci` e `npm run dev`. Publicação: `npm run build`. GitHub Pages em `/variaveis/`.
